1.  timeit.timeit() measures the total time to run an indicated block of code a number of times (number = ...) while timeit.repeat() similarly runs a block of code an indicated number of times but returns a list of values from having run timeit.timeit() with the indicated number over a specified repeat value (repeat = ...). timeit.timeit() can be favoured more for single measurements of code times and quick comparisons while timeit.repeat() can be used to analyze code over a number of times while allowing variability analysis (from multiple return values) by running the entire timeit.timeit() testing multiple times.
2.  timeit.timeit() output should be the average value in order to give an indication of the typical code runtime. timeit.repeat() output should be min to return the best case time of the code.
